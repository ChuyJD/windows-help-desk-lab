# Windows Help Desk Troubleshooting Lab

A hands-on IT support portfolio documenting Windows 11 troubleshooting scenarios commonly encountered in Tier 1 help desk environments.

These labs demonstrate my approach to diagnosing technical issues, using Windows troubleshooting tools, documenting findings, identifying potential causes, and verifying system functionality.

## About This Portfolio

I created this lab to strengthen and demonstrate practical IT support skills while preparing for an entry-level Help Desk / IT Support role.

Each ticket follows a structured troubleshooting process:

**Ticket → Symptoms → Troubleshooting → Findings → Resolution → Verification**

The labs focus on understanding why each troubleshooting step is performed rather than simply running commands.

## Help Desk Tickets

### Ticket #001 — Network & DNS Troubleshooting

Troubleshot a simulated Windows 11 internet connectivity issue by testing:

- IP configuration
- Local gateway connectivity
- Internet connectivity
- DNS name resolution
- IPv4 and IPv6 DNS behavior
- DNS cache
- Network path

Tools and commands used include:

`ipconfig` • `ping` • `nslookup` • `tracert` • `ipconfig /flushdns`
